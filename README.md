# Formation API

## Description

Mini-projet Java Spring Boot permettant
de découvrir le développement d'une API REST.

## Technologies

- Java
- Spring Boot
- Maven
- JUnit 5
- AssertJ
- Cucumber
- Rest Assured

## Fonctionnalités

- Consulter les utilisateurs
- Consulter un utilisateur par ID
- Créer un utilisateur
- Supprimer un utilisateur

## Tests

Tests unitaires avec JUnit et AssertJ.

Tests d'API avec Cucumber et Rest Assured.
